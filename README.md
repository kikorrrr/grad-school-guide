# 高性价比读研指南

选导师时听到「能实习」，怎么问到谁真的出去过？导师没审，中期明天截止，还能做什么？这份指南写给中国大陆的拟读研和在读硕士。每篇先给一件能动手的事，再放具体问法、真实经历和可核对的出处。首版涵盖统考、推免、学硕、专硕和在职读研。

## 明后天就截止

| 手里的事 | 今天先做什么 |
|---|---|
| 导师没审，明天中期截止 | [分别核学生提交和导师审核的时限](实用篇/导师关系和同门协作.md#明天中期截止导师还没有审核)，同时问学院本批还有没有补交方式 |
| 实习两天内要答复，校内审批还没下来 | [同一天问学院何时回签、问招聘方能否改日期](实用篇/从研一开始准备实习.md#邀请只给四十八小时审批还没走完) |
| 单位催报到，毕业证或学位证还没发 | [问学院最早发证日，再问单位能否延期或用临时证明](实用篇/在读安排与毕业兜底.md#单位催报到双证还没发) |
| 第一家催签，第二家还没面完 | [先问两家的实际答复日，再看协议](实用篇/读研琐事快查.md#第一家催签第二家下周才终面) |

## 还没入学，或正在比较项目

| 你正在决定什么 | 从这一步开始 |
|---|---|
| 考研、推免、直接工作还是在职读 | [把一个能报的项目和一份愿意做的工作放到同一张表](高性价比读研指南.md#一要不要读) |
| 同名专业，校区、联培和名额可能差在哪 | [抄下当届招生目录里自己那一行](实用篇/选学校和导师前怎么问.md#先把学校和这个项目分开看)，核真正的培养地和名额 |
| 想打听课题组，手里一个熟人也没有 | [找一位同项目在读生，只问一件他亲手做过的事](实用篇/选学校和导师前怎么问.md#先找三类人各问一件对方亲手办过的事) |
| 老师说「不影响毕业就行」，我想研一暑假自己找实习 | [问上一位是研几，谁找单位，谁批](实用篇/选学校和导师前怎么问.md#老师说实习可以先问上一个人怎么出去的) |
| 学长说不用发论文，导师说毕业没问题 | [从一批毕业生的领证日往回找，再核自己这届](实用篇/选学校和导师前怎么问.md#老师说毕业没问题请对方从最后一学期倒着讲) |
| 组里有设备、有项目，我去以后用得到吗 | [只问最依赖的那一样，新人何时第一次用上](实用篇/选学校和导师前怎么问.md#每天究竟跟谁干活做不下去谁能接) |
| 老师口头答应了，发现课题不合适 | [问互选是否报送或确认，最晚哪天能改](实用篇/不同经验怎么选.md#老师说可以来还没互选现在还能改吗) |
| 两份录取要回复，学生和导师的说法对不上 | [写下两条会让你改选的条件](实用篇/选学校和导师前怎么问.md#问到的说法不一样今晚还得回复)，把最后一通电话用在其中一条 |

想看整个过程，从[通用篇](高性价比读研指南.md)顺着读。报考名额、双选和联培详见[择校择导](高性价比读研指南.md#二怎么选学校和导师)。[四张可直接填的表](高性价比读研指南.md#四张可以直接填的表)放在文末。

## 在读遇到事，先查这里

| 眼下卡在哪 | 可以先做什么 |
|---|---|
| 导师只说「再改改」、消息不回，或几件任务同时要交 | [拿一小段改稿去确认下一版交什么](实用篇/导师关系和同门协作.md) |
| 每周都要组会，实验时间越排越散 | [记一次准备时间和会后得到的具体反馈](实用篇/不同经验怎么选.md#每周组会究竟值不值) |
| 总想同门怎么比我快，囤了一堆课还没动手 | [写三行，再挑一个能给别人看的小任务](实用篇/少内耗和走出学生思维.md) |
| 要开题、中期或送审，还不知道谁审、哪天截止 | [用本届通知排下一项考核](实用篇/在读安排与毕业兜底.md) |
| 研一想实习，想知道自己现在能投什么 | [拿课表对两份真实岗位](实用篇/从研一开始准备实习.md) |
| 想转行业，没有相关实习 | [从三份岗位里挑一个能做成作品的任务](实用篇/考公考编与其他去向.md#想换行业没有相关实习)，例如[用公开订单表做一次数据分析](实用篇/从研一开始准备实习.md#跨专业零实习先用一张订单表做作品) |
| 在职上课或考试和班表冲突 | [把返校日和下一轮排班放在一起](实用篇/在职跨专业和文科怎么读.md#在职读研把返校日期和班表放在一起) |
| 跨专业进组，搞不清该先补什么 | [选一项能让同门当场检查的小任务](实用篇/在职跨专业和文科怎么读.md#跨专业新生先做一项能被检查的小任务) |
| 访谈约不到人，关键档案也拿不到 | [找谁确认材料、最迟等到哪天](实用篇/在职跨专业和文科怎么读.md#做访谈或查档给材料设一个确认日) |
| 学分和成果够了，论文迟迟没送出 | [查停在学生提交、导师确认还是学院受理](实用篇/在读安排与毕业兜底.md#学分和成果都够了论文还没送出去) |
| 三助、报销、投稿或离校手续没办过 | [查哪位经办、需带什么](实用篇/读研琐事快查.md) |

两种经验说得都像有道理时，可以查[提前进组、实习、定题和小论文的反例](实用篇/不同经验怎么选.md)。

## 读懂一条建议

文中的半小时、一份表或两条消息，是读者先要投入的工夫。等到回复、办成手续还要单独算。证据等级只说明这一条依据支持到哪里。

| 证据 | 能说明什么 |
|---|---|
| A | 对应院校、届别或岗位的正式文件，或在明确条件下可复核的实证结果。 |
| B | 相关研究、技术文档或条件清楚的案例。用到自己的项目时，再核差别。 |
| C | 个人经验、平台个案或编辑建议。适合借问法和试做步骤。 |

政策与公开样本有查阅日期。实际资格、金额和申请日期回当届文件查。平台材料的可见范围和原链接见[创作者和原作索引](调研/创作者索引.md)。
