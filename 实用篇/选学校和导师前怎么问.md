# 选学校和导师前，怎么问到实话

[回项目首页](../README.md) · [通用指南的学校和导师篇](../高性价比读研指南.md#二怎么选学校和导师) · [入学以后真卡住了怎么办](读到一半要改计划.md)

今天只来得及问一件事，就挑那件**答案一变，你就会换学校或换组**的事。比如你想研一暑假实习，先问同项目上一位自己找单位的人什么时候去的、谁批的。老师说可以，师兄说有人去过，师姐说她当时没走成，三句话可以同时成立。把各人说的是哪次、最后办到哪一步问清，才有得比。

## 先把学校和这个项目分开看

**给每个备选项目留半小时，抄下当届目录里自己要报的那一行。** 记院系、专业代码、学位类别、学习方式和专项，再核哪儿上课、哪儿做课题、什么时候分导师。目录里看不出来，就拿这一行问招生办：「我报的是这个项目，想联系的老师还有这类名额吗？哪一步才算分到组？第二年通常在哪做课题？」这样能提早算出驻场或租房的开销，也能发现老师手里的名额是否正好是你能报的那一种。还要入学后双选的，先看看没进意向组时有哪些方向自己也愿意读。

录取通知上的校名一样，课可能在主校区，研二工位却在企业基地。比如中国药科大学面向 2027 级拟录取推免生的互选通知，普通推免硕士在线填导师志愿，国家工程硕博士另有沟通、签字和提交材料的安排。把「老师愿意聊」「这个类别今年能招」「还有可用名额」「系统已经确认」四件事分别核。西安交大 2027 年招生资格审核通知也说明，有的导师新增招生学科、培养层次或类型，须按本年度要求申请。 [中国药科大学 2027 级互选通知](https://yjszs.cpu.edu.cn/c7/fa/c10854a247802/pagem.htm) · [西安交大 2027 年导师招生资格审核通知](https://gs.xjtu.edu.cn/info/1148/11457.htm)

**真实例子，师姐推荐了组，名额要再问当年。** 华中农业大学学硕张茹楠说，初试后问了做毕设的实验室里的师姐，师姐觉得意向组经费较充足、研究有潜力。她又听了毕设导师的意见，然后直接联系准备报的老师梁梅。梁梅在同一篇记录里说，起初告诉她可能没有名额，后来一位原计划来的推免生没来，她过复试后才有这个机会。文章写到她研二，梁梅回看她进组一年，实验上手快，也还有记录不细的问题。组内消息帮她找到了值得联系的人，名额则取决于当届变动。同篇赵晴的邮件问得更具体，个人主页写招两人，学院已有两名推免公示，还有没有名额？这些是导师组织学生写的入组回顾，能看到本人经历和导师补述。 [梁梅与学生的双向选择记录](https://blog.sciencenet.cn/blog-3598841-1500980.html)

另一位推免生在个人博客里记了一次名额上的误会。已经决定去中山大学时，一位老师说有名额，他追问才知道是学硕，用不上自己报的专硕。最后他在组内又联系到有对应名额的老师。原帖写到择校和名额，没有在读后续。问「还有吗」时，把学位类别、招生渠道、登记在哪位导师名下和日常谁带一起说出来。 [Orange Cheers! 本人复盘，见 9 月 27–28 日](https://blog.caseylia.com/posts/baoyan/)

下面四件事，拿到两份录取的人当天就能查。

| 要核什么 | 找谁，怎么问 |
|---|---|
| **培养地** | 问院系招生办或项目教务。「我这届每学年通常在哪上课、做课题和答辩？驻场是必选还是后续选拔？」录取前没有定单位的，也问什么时候确定。 |
| **住哪、什么时候出钱** | 查当届住宿条款，问的是自己能不能申请、安排几年和在哪住。再找上一届同项目的人问搬过几次、第一次房租和押金什么时候交、到实验室实际多久。 |
| **谁接收、谁日常带** | 找招生办确认当届名额类型和互选日期，问导师登记在谁名下、平时跟哪位老师或同门做事，第一学期的通常安排是什么。 |
| **如果没进意向组，或联培中途变动** | 问学院这一类学生还可以选谁，没人接由谁协调。联培再核合作方退出时由谁接回、课题与已有数据能否继续用。 |

别拿同校另一个项目的宿舍和校区补空白。复旦 2027 年简章对专业学位硕士校内住宿列了特定例外，其他通常自行安排。上海交大 2027 年海南专项则把第一学年校内学习、后续联合培养基地学习和入企期间住宿支持分别写在项目说明里。先找这种白纸黑字，费用再用自己的预算和实际路线算。 [复旦大学 2027 年硕士招生章程](https://news.fudan.edu.cn/2026/1009/c45a150578/page.htm) · [上海交大 2027 年海南专项说明](https://yzb.sjtu.edu.cn/storage/gs/web/yzbcn/article/2026/10/fa8d5053f700060ddeabaf0fb40f781d.pdf) · [房租和跨校区通勤怎么算](没人提前说的几件事.md#房子便宜先走一遍从门口到工位的路)

## 先找三类人，各问一件对方亲手办过的事

先翻**一个课题组成员页或一个校友群**，给同项目的人发一条短消息。有愿意聊的，先约十来分钟，只问一件他亲手做过的事。比如想知道平时有没有人带，问「你第一次交实验结果，谁告诉你下一步怎么做，等了多久？」这样聊上几句，就能知道对方平时从哪里得到反馈。暂时只找到一位研一，就先问带教，实习和送审同时去查公开通知。

**一位同项目在读生。** 学院开放日、夏令营、本校已去那边的校友也能帮你找到人。请导师推荐一位可以，再从另一个自愿渠道找一位。先确认对方是哪个项目、哪年入学、平时跟哪位老师做，再问带教、校区或排班。想认识高年级或毕业生，请对方帮忙转达联系意愿，让对方自己决定是否回复。

**一位已经毕业或正在送审的人。** 优先找最近一两届、培养类型接近的。公开毕业访谈和校友活动能找到方向，再用对方公开的联系方式，或请认识的人征得同意后转达。问对方自己走过的那次送审或找工作，不让对方替师弟师妹评价。只联系得到一位时，就在记事里写「一位、某届、本人经验」，别拿他的结果替整个组填一行结论。

**一位真受理该事项的人。** 名额、专项和互选找院系研招，培养安排和实习找教务或培养办，送审和成果认定找学位经办。学生告诉你上次哪一步要找谁，到了自己这届，用经办人的答复确认手续。没找到毕业生时，还可以先看近届公开培养与学位通知，向学院问有无本项目汇总或公开校友经验。查不到的就留「未核到」，别为了把表填满去打听个人遭遇。

第一次只发两三个问题，留对方不答的余地。下面都是可改用的消息。

> 学姐好，我准备报 [学院和项目]。方便问一件你最近遇到的事吗？比如入组后第一次交读书笔记或实验结果，是谁先看的，隔了多久才知道下一步该做什么？简单说一下就行，不方便也没事。

> 学长好，我在比较 [项目]。想问你自己毕业那一学期，哪月交初稿、哪月送审、哪月拿到证？其中最容易耽误的是成绩、成果认定，还是导师审核或等下一批？不涉及你同学的个人情况。

> 老师您好，我在考虑报考 [入学年度、学院、专业代码、学位类别或专项]。请问 [研一暑假自行联系单位实习／本届学位成果认定] 适用哪份文件、由哪位老师受理？我看到 [文件名或旧通知]，想确认它是否也适用我这一届。

不要把对方的私聊转发到招生群，也不要反问「你说真的？」。如果只收到「导师很好」「挺自由」，换成「上一次你提出和导师方案不同，最后怎么定的？」有人只愿意说一两件事，尊重这个范围。自己记录届别、条件和流程，省掉能认出个人的细节。要给学院核规则，提项目和问题就够了。

## 老师说实习可以，先问上一个人怎么出去的

**花十分钟发两条消息。** 问同项目高年级生「上一个自己找单位出去的人是研几？走之前先交了什么？」再问培养办「我这一类学生，导师同意后还要谁批？实习跨到开学怎么办？」先分清单位是谁找的，再谈月份和时长。能去指定企业做培养实践，和能去自己投的暑期岗，差的可能是整个招聘窗口。

已经看中一类岗位，就按它的排班问。例如「我想研一暑假去自己投的研发岗，六月底到岗、每周四天、连续三个月，会跨到研二开学。有同类型的学生这么办过吗？最迟哪天要完成哪项任务、谁签字，开学那几周要回来吗？」导师说「不影响进度就行」，可以接着问按过中期、交样机还是论文录用来判断，实验撞期时哪边的日期能动。研二有人去过，能帮你找到手续。你想提前一年去，得再把课程和前置条件问一遍。

**知道要去指定单位，后来才确认自己占的是企业培养名额。** 虫部落一位研零发帖人说，他原本就知道导师说的实习要去指定单位。拟录取显示普通专硕，他当时没再问，后来才由院系招生老师确认自己对应企业培养名额。发帖时尚未见到适用协议，也没确认换导师的流程，后续去向未见。确认志愿前，把培养名额、指定单位和能否再自行找实习分开问。 [虫部落当事人原帖](https://www.chongbuluo.com/forum.php?mod=viewthread&tid=24657)

**另一位把就业方向先说了，后来导师同意他去。** 牛客上一位从计算机调剂到材料的硕士说，开学前初见，导师问他的职业规划，他把想做互联网开发直接说了。研二寒假之后拿到滴滴的实习录用，导师同意他去。他把提前做实验、留出时间做小论文看作自己能去的原因之一。同一账号在九月又更新，说自己在腾讯实习后拿到转正，随后公布了腾讯和字节的秋招录用。帖子写到了选工作，正式报到没有后续。对你有参考的是「有过导师实际同意」和当时的年级。想在研一出去，要另问能提前到什么时候、哪些任务得先交。 [牛客作者求职复盘](https://www.nowcoder.com/discuss/616669514201063424) · [同一账号的实习、秋招更新](https://www.nowcoder.com/users/271775959)

**上一次实习顺利，第二次却撞上交论文。** 《中国新闻周刊》转述一篇硕士论文里的访谈。受访学生去过导师介绍的实习。后来她在导师催交论文时自己报名另一段实习，导师认为这样会耽误论文，两人也早已在选题上有分歧。学生最终换了导师。公开报道能追到换组，第二段实习是否去成没有交代。有人说组里去过实习时，可以问「去的那一次是谁找的？如果碰到开题或交稿，上一位最后改了哪边的日期？」 [《中国新闻周刊》报道，华龙网转载](https://news.cqnews.net/1/detail/1163211006263611392/web/content_1163211006263611392.html)

> 学姐，我听说组里有企业实践。我想分清规定的实践和自己找的暑期岗位。你本人或你经手过的最近一次，单位是谁找的、哪个学期出去了、哪一步最花时间？如果有人拿了 offer 最后没去，知道流程卡在哪一环就行。

**把口径拿回学院。** 问「本项目的专业实践、自己找的工作实习和离校请假是同一张表吗？导师同意后还要谁批准？申请通常要提前多久？」兰州大学物理学院的一份通知就分别列了不同校外活动的办理要求。南京大学一位导师的公开组规更能看出差别，他把硕士有没有一篇特定级别论文、是否已到研二下以及毕业进展分开写。这个组的说明有自己的时间背景，拿来学问法，具体必须等自己那届的答复。 [兰大物理学院校外活动通知](https://phy.lzu.edu.cn/info/1194/16547.htm) · [南京大学教师公开的课题组说明](https://cs.nju.edu.cn/wujx/For_Students.html)

如果在读生说一个人都没出去，先问是没人想去、没拿到 offer、课时排不开，还是有人正式申请没获批。这四种情况差很多。牛客有位做转码求职复盘的作者说，自己拿过实习录用，看组里此前无人出去就没向导师开口。这个经历能证实他当时没提出申请，导师实际会怎么判还没试过。反过来，某届有人去了，问他是本组常规做法、联培任务，还是赶在答辩之后才获同意。 [牛客作者求职复盘](https://www.nowcoder.com/discuss/353158653773553664?sourceSSR=users) · [拿到实习后怎么谈时间](从研一开始准备实习.md)

## 老师说毕业没问题，请对方从最后一学期倒着讲

**用一刻钟把最近一批毕业通知倒着抄三项。** 从领证日期往回，找答辩、送审和导师确认的截止日。问一位同项目毕业生，他本人靠什么材料进了那批，哪一步差点赶不上。很多人只记得六月答辩，真正决定能不能赶上六月的，可能是早几个月的材料认定或第一次送审。近届日程可以估间隔，你这一届的成果要求还要另查。

如果毕业生说不用发，官网写了成果门槛，把原条款带给学院学位经办。「我是 [届别、项目和学位类型]，这条适用于我吗？项目或实践成果有没有明文认可的办法，什么时候交，由谁认定？」替代条件没确认前，先按已查到的当届要求算。

**真实例子，入组前听到不用发，后来组里开始按人算积分。** 计算机专硕亦非回忆，入组前和一位帮他看本科毕设的学长聊过。学长说专硕按组安排做项目，无须发论文。作者后来记述，组里的论文积分从按老师汇总变为按个人算，实习规则也有调整。文章还记录了双方对一次组会说法的不同理解，作者听到的是不用发，导师后来解释的是不用单独发。据他自述，四月通过外审，五月按当时的担保答辩安排提交了导师签字的材料并通过答辩，六月领了双证。下次有人告诉你「不用发」，接一句「这适用哪一届？上一位同类型学生当时凭什么材料进了送审和答辩，谁给确认的？」 [亦非本人长文，见「前传」及后文毕业经历](https://www.yifeil.com/posts/dongwuwangshi)

**已经到毕业那年，「再做两个月」也能看走眼。** 豆瓣上有位原定 2021 年毕业的学生发帖说，四月导师觉得再补两个月工作量就能毕业，八月原来的研究却做不下去，改了方向。九月初导师还觉得能赶冬季毕业，月底又指出研究问题不够明确。用人单位最后没有批准延期报到，明确原录用将在年底到期。发帖人次年五月说自己还在延毕，最终哪天拿到证没有查到。选组时可以问毕业生「原课题做不下去，组里上一次是怎么换的？赶不上送审截止日期，实际上等了几个月？」 [豆瓣本人原帖与 2022 年 5 月 27 日楼主回复](https://www.douban.com/group/topic/251124278/)

「毕业条件」至少分三层问。

| 先核哪一层 | 具体要的答案 |
|---|---|
| **学校和学位点的要求** | 同一入学届、同一学位类别用哪份文件。论文、项目或实践成果哪些可认，录用、见刊、检索属于哪个阶段，署名、单位、成果与论文关联有什么要求。 |
| **组里上一位怎么走的** | 实际用哪种成果、预答辩前要过什么、论文从哪一版开始由谁改，导师审核一般在什么时候。遇到合作方不让公开或稿件被拒时，有无经过认可的替代做法。 |
| **毕业当批的日程** | 拿一份近届通知，从领证往回倒。学位会、答辩、盲审、导师审核何时截止。错过一个月是否只是多等一个月，还是直接跨到下一批。 |

辽宁师大的 2026 年下半年通知明确，学硕科研成果按入学当年的要求核，同时把学生上传及导师审核列成两个时限。上大环化学院给 2026 届的办理通知，把接收函、检索材料和特殊署名的处理分开列。用近届日程做预估，入学年份的要求另查，有疑问请学位经办给出处。导师或同门说「我们组习惯再加一篇」时，问这是希望做到的培养目标，还是不到就不协助送审，学院认可的替代路径是什么。 [辽宁师范大学当批学位申请通知](https://master.lnnu.edu.cn/info/1034/2791.htm) · [上海大学环化学院 2026 届流程](https://ece.shu.edu.cn/info/1304/87134.htm)

> 学长，我不问具体谁延了。想请你回想一下你自己那届，有没有遇到送审前还有成果待认定、导师没来得及看稿、或者盲审后要改的情况？你当时是哪一步最费时间，谁能决定下个日期？

「这一届毕业的七个人都去哪了」和「当初进来的有几人，多少人按原批次毕业」是两道问题。兰州理工大学一个学院的公开报道写了某组 2026 届七名毕业生的去向，五人读博，两人就业。报道统计的是这七名毕业生。想判断自己有没有可能按时毕业，至少要知道哪一届、哪种硕士、从哪批入组开始算。没人能给可靠汇总，就记住问到的两个具体过程，人数空着。也别把好几个同门转述的同一个师兄，当成好几个样本。 [兰州理工大学学院毕业报道](https://jizhi.lut.edu.cn/info/1301/12633.htm) · [毕业节点卡住后的真实经历](读到一半要改计划.md#盲审没过该申请复核还是改稿)

## 每天究竟跟谁干活，做不下去谁能接

**约一次短聊，问在读生入组后第一次自己上手是在什么时候。** 只挑你最依赖的一样东西来问，比如训练账号、实验台架或能合法用于论文的访谈资料。问他等了多久、谁开了权限、卡住时找谁。再问导师你头一个月通常跟谁做事。带教人和可用条件都能说到具体安排，比进门看一圈设备更能帮你估算头一学期做不做得出东西。

**电话里说提前进组能学到东西，进组后有些设备轮不上。** 《中国科学报》刊发的王博（化名）口述中，复试后有导师主动打电话邀他，他当场答应。对方说提前进组可以学到很多，他真正进去后回忆，自己很少参与研究，一些设备轮不上，组会上的反馈也经常停在鼓励层面。后来申请另一位导师的博士项目时，他先从好几个渠道打听过新组。采访止于申请阶段，后面的录取和新组体验没有交代。这个故事最适合拿来问「新人能用的东西是什么」「老师实际给的是什么反馈」，也说明短暂参观能看到的有限。 [王博口述，《中国科学报》记者整理](https://news.sciencenet.cn/sbhtmlnews/2026/1/388198.shtm?id=388198)

**师姐讲以往怎么招，导师说这次怎么定。** 何刚在陕西师大院所刊登的回忆里写，硕士复试后先从在意向组做毕设的同学处打听，再请管过组内事务的高莉宁师姐确认。师姐告诉他按前些年的做法，他这个名次不会被收。他请师姐转达，房喻面谈时解释了自己担任行政职务时为什么通常不收第一名，后来同意接收他。何刚当年实际进了组，也记下开头的课题指导和导师通常傍晚进实验室。这是多年后写的回忆。今天遇到同样的说法，可以顺着问「那是去年怎么招的，这次我符合什么条件，还要走哪一步？」 [何刚本人回顾，见「叩门」「入室」](https://yfang.snnu.edu.cn/info/1086/9924.htm)

到了能聊具体题目的时候，再把三处容易断掉的安排问清。

- **问日常带教。** 「我头一个月跟谁、什么时候能见一次？带我的人下半年毕业了，接下来找谁？」带教的同门能教方法，课题方向和学位签字还要问对应负责人。
- **问资源够不够自己用。** 「上一个新生从入组到拿到数据或上机权限等了多久？第一次坏掉、排不到或数据不让出，谁帮他换方案？」工科把培训、场地和经费问到实际经办。大模型问排队、账号和试跑预算。访谈和档案问介入和使用权限。
- **问任务变了怎么接。** 「企业项目验收要什么，学位论文还需什么？合作方退出或不能公开时，上次有没有换成可用材料的例子？」如果连这个题至少能用哪一部分都说不清，先把它记成有依赖的选项。

真把换组当作后手的话，提前问培养办「如果原导师调离，或我需要改题、换组，哪些老师有资格接？能跨到另一个学院吗？没人接时学院有没有安排谁暂时指导？」V2EX 一位研二发帖人找到过愿意接收的外院老师，还参加过几次组会，最终跨院变更没有获批。先核自己的项目能调到哪里，再把意向组以外还有没有你愿意读的方向算进去。 [当事人原帖](https://v2ex.com/t/1047521) · [想换导师但暂时没人接的后续与校规](读到一半要改计划.md#想换导师暂时没人接)

有开放日就约一次获准旁听，留意会后是否有人确认谁来做、何时复查。也可以带一张公开组内论文的图，请同门讲它怎么做出来。把那一次观察写清，后续用同项目在读生的经历核。若导师建议暑假来做几周，再看 [怎样约定试做任务、带教和结束日](不同经验怎么选.md#要不要提前进组先问暑假结束时会留下些什么)。 [大模型组的算力问题](../专题/大模型读研要算的账.md)

## 问到的说法不一样，今晚还得回复

**只剩今晚，就用十来分钟写下两条会让你改选的条件。** 比如必须能研一暑假自主实习，或家里负担不起两年校外房租。两边各写「谁说的、适用哪一届、还差谁确认」，把最后一通电话用在最可能改变选择的那一行。答复前来不及确认的写「待核」。要是离开那个组就没有自己愿意读的方向，导师分配还没确定，本身就会影响选择。

| 会改变决定的事 | 项目甲，谁说的，哪届 | 项目乙，谁说的，哪届 | 还差谁确认，最迟哪天 |
|---|---|---|---|
| 研一暑假能否自主找单位，走哪条审批 |  |  |  |
| 没有论文录用，哪种成果可认、谁同意送审 |  |  |  |
| 基地、住宿和科研在什么地方，费用多少 |  |  |  |
| 第一学期谁带，关键数据或设备何时能用 |  |  |  |
| 意向导师没落实，能否在同类项目里另选 |  |  |  |

两个人说法不同，先问「你说的是哪一年、哪种学生、哪一步办成？」举个假设。研一转述「可以实习」，一位刚毕业的人说「我的研二暑假等中期审核完，自己找单位，经学院批了，期间每周回组一次」。后一条能帮你看清那一届怎么走。想把它用到你研一暑假，还要问这个时间和回校安排是否允许。

假设你必须在研一暑假完成一次自己找的研发实习。甲校的老师口头欢迎，但同类学生只有企业指定实践的例子，学院当晚也确认不了自主实习；乙校最近有人按你想要的月份和天数办成，学院能给出你适用的流程。即便甲的名气更大，这项条件也足够让你重新排序。反过来，如果你想先做一年连续实验、实习可以放到研二，甲的现场资源、老师亲自带的时间都可以重新比。到了必须确认的时间，按已经核到的条件决定，把靠后续运气才能兑现的事当作未知。

如果关键答复还差一步，可以发一条确认消息。

> 老师您好，感谢您介绍组里的安排。我理解目前是 [普通或专项类型／尚未确认]，导师在 [时间或环节] 确定。对我比较重要的是 [可自主实习的实际时间／送审认定路径]，我理解的条件是 [两句]。请问我理解得对吗？如需找学院核，能否告诉我该看哪份通知或联系哪位老师？
